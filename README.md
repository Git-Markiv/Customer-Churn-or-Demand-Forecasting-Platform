# Customer-Churn-or-Demand-Forecasting-Platform
ChurnLens is an end-to-end customer churn platform: SQL feature extraction, automated cleaning, EDA and feature engineering, then cross-validated, tuned comparison of Logistic Regression, Random Forest, XGBoost and LightGBM. SHAP explains every prediction in an animated Streamlit dashboard with what-if and ROI tools, for demo or custom data.
